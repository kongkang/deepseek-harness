# 外脑界面原型

[English](README.md) | 中文

这个目录包含一个独立产品界面，用于在 DeepSeek Harness 上运行一个公开对话与多个持续脑分支。它不导入现有的 DeepSeek Harness Web UI，但会使用相同的 Host API 和已配置模型提供方。

## 运行

在仓库根目录运行以下命令：

```sh
pnpm run waibrain:dev
pnpm run waibrain:test
pnpm run waibrain:typecheck
pnpm run waibrain:build
```

开发命令会输出本地预览地址。

其他本地进程已占用默认 UI 与 Host 端口（`5173` 和 `4174`）时，可通过 `WAIBRAIN_UI_PORT` 与 `WAIBRAIN_DSH_PORT` 覆盖。

## 产品交互

- 创建对话前先配置一张角色卡，分别描述身份、性格、说话方式、关系场景、开场白、对话示例和主系统提示词。
- 配置、编辑、暂停和重新启用脑分支。每个分支只有一项职责，并拥有独立系统提示词、模型、思考强度和可选的工作 agent 启动权限。
- 在运行中的对话右栏外挂新脑分支。新分支会立即加入当前系统，并接收后续用户消息。
- 先把一条用户消息发送给公开对话，再并发发送给每个已启用脑分支。每个栏目都运行在独立、可持久化的 DSH Session 中。
- 先查看主对话回复，再查看简洁的脑分支报告及其推送状态。
- 在认知时间轴的同一套栏目栅格上对齐用户消息、公开回复和脑分支报告；小屏幕会把栏目转换为带标签的纵向卡片。

## 当前范围

界面通过 `llm.models` 读取部署的模型目录，不读取或暴露设置文档。主对话与脑分支的选择通过会话级 `session.selectModel` 应用，因此 demo 不会替换 DSH 的共享默认值。人物角色和脑分支的 System Prompt 存在各自 Session header 中，可跨持久化、恢复和 fork 保留。界面仅在完整 1+N Session 集合创建成功后发布绑定，因此部分创建失败后的重试会为每个栏目使用当前配置。脑分支报告以简洁注入上下文发送给主 Session，`[[silence]]` 则保持内部状态。从脑分支启动工作 agent 仍不在本次范围内：界面可以配置并显示权限，但尚不会调用第三层 agent。界面绝不展示隐藏推理记录。
