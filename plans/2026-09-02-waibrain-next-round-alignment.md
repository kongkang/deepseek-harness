# 外脑下一轮开发对齐记录

日期：2026-09-02 · 状态：P0 已对齐，P2/P3 待产品负责人展开

依据：[2026-08-30 语音AI想法录音转录](2026-08-30-waibrain-voice-ideas-transcript.md)与 2026-09-02 对齐讨论。另一会话推进的[持久化第一阶段](2026-08-24-waibrain-phase-1-development-plan.md)不在本文范围。

## 对齐结论

### 1. 语音流水线：挂起

非实时 STT→润色→模型→TTS 流水线与实时双工接入全部搁置，本轮不开发。相关机制讨论转为设计备忘。

### 2. 普适性判定收敛为背景搜索外脑

录音中「检索 N 篇佐证判断需求普适性」仅为示例。实际需求是给 Agent 增加一个背景 Web Search 外脑：用户表达期间后台检索，结果以闪念回灌。普适性确认只是该外脑的一种提示词用法，不做专门功能。

### 3. 表演层「不说话」标记

闪念通道已具备，差在输出语义。方案：表演层在判断不该说话时输出固定标记（如 `<不说话>`），满足「模型必须输出字符才能结束轮次」的机制约束；输出处理层识别标记后结束该轮、不产生用户可见内容、从展示中剥离标记、会话日志完整保留（模型可见⟺日志）。识别影子侧已有「闪念为空不注入」的等价语义，标记只需在表演层实现。哨兵文本优于结构化输出：表演层零工具且流式输出，结构化通道成本更高。

### 4. 双工打断与上下文回退：设计可行，随语音层一并挂起

机制与既有 fork 前缀设计一致；主对话侧需要新增上下文投影截断能力。见设计备忘。

### 5. 三种交互模式：不建模，转用例

大段表达+后台调研 / 类人际沟通 / 异步任务三种场景不做专门模式开发。目标是通用方法；三个场景进入用例清单，作为通用方法的验收用例，通用方法在各场景下的自然应对即符合交互模式要求。

### 6. 树形冒泡结构：现阶段只做两层

层级原则：越往下时间跨度越久、任务颗粒度越细；第二层无法快速解决的问题才向下走到第三层。

现阶段只实现第一层和第二层：

- 第一层（Talker 表演层）与第二层**同时**收到用户的描述和对话，不分先后、互不等待。
- 第二层是用户有意识配置的**注意力分支**（例如用户近期关注减肥，分支展开为饮食、运动、睡眠），跨轮次长期存在。
- 分支默认不说话：日常对话（如聊工作）未命中分支时，反馈为「不说话」，不产生任何注入；对话命中分支内容时，该分支请求说话，冒泡到第一层。
- 表演层收到冒泡后判断是否表演、如何表达，最终到达用户。

第三层（长程任务执行层）暂不实现：例如健康分支下的非实时轮询、监听 Apple Watch 数据等长程任务。第三层有数据变化或值得提醒的内容时，先冒泡到第二层，由第二层感知后再冒泡到表演层。第三层及以后更偏向传统的问题解决式 Agent，不属于当前树形冒泡结构的开发范围；对它的唯一接口约束是「向上冒泡进入第二层」。

### 7. 输出预算：场景自适应简报

不按用户要求的字面长度执行，而是以当前对话场景（语音/屏幕/大屏/上下文）计算合适的输出形态；语音场景默认简报式，「详细展开」也以简报框架展开。

## 设计备忘（挂起项的机制记录）

- 上下文回退：用户听到 10%、模型已输出 50% 时，用户侧上下文回退到实际播放的句子边界（非任意 token 位置），后续按截断前缀继续；未播放部分不进上下文。子对话（闪念）无需单独对齐——现有实现每轮从主对话真实前缀重新 fork，影子自身历史不延续，主对话回退自动传导到下一轮影子。主对话侧需要「投影截断」：日志保留全部并记录截断事件，下一轮 prompt 按截断点投影构建，满足模型可见内容可从日志重建的不变量。截断会使主模型前缀缓存命中缩短到回退点之前，属允许的浪费范围。
- 树形冒泡与现有实现的映射：第二层注意力分支 = 外脑/影子配置（跨轮次持久）；每轮从主对话前缀 fork = 与第一层同时收到对话；识别影子判定不相关、不注入 = 分支默认不说话；命中后闪念注入 = 分支请求说话；Talker 决定是否表达 = 表演层判断。冒泡落点是表演层的下一个 step 边界：本轮仍在输出则当轮生效，本轮已结束则下一轮生效。第三层未来接入时只需向第二层提供「数据变化/值得提醒」的冒泡输入。

## 待决问题

1. 注意力分支的增改途径：现阶段按外脑卡片手动配置处理；用户在对话中用自然语言要求新增分支（如「最近帮我多关注减肥」）是否属于本期范围？这涉及自我更新能力，持久化第一阶段已明确排除。
2. 双工回退场景中未播放的输出：仅留日志归档（不进上下文），还是彻底丢弃？（属挂起的语音层，不阻塞本期）
