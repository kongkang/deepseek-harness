ReAI 语音把两件事放进输入栏：**听写**（麦克风按钮，录音转文字进草稿）与**语音翻译**（地球按钮，译文直接进草稿，中文与英文自动判断方向）。识别走本机 SenseVoice，翻译走本 bundle 的 translator 服务。

键盘操作（可在快捷键设置中改绑）：

- 进入对话输入（Web 默认 ⌘/Ctrl+Alt+I）——任何界面状态回到输入框，没有对话时自动新建；
- 语音听写（⌘/Ctrl+Alt+V）与语音翻译（⌘/Ctrl+Alt+T）——开始/结束一次录音；
- 打开/关闭对话列表（⌘/Ctrl+Alt+L）——↑↓ 选择、Enter 打开、Esc 关闭。

插件详情页提供识别引擎设置（本地模型 / 云端模型·即将支持）与本地模型准备卡：显示 SenseVoice 是否已下载，提供「下载并准备」、取消、重试，网络慢时可切换到 Hugging Face 国内镜像。模型未就绪时点输入栏的两个按钮不再静默失败，而是弹出同一张准备卡和安装引导。浏览器只在安全上下文里开放麦克风，所以用 `http://192.168.1.5:3081` 这类局域网 http 地址打开时无法录音：控制台会提示浏览器禁用了麦克风，并指引改用 `https://` 或 localhost。录音前请给 DSH 配 TLS，或在本机用 `http://localhost:<端口>` 打开。
