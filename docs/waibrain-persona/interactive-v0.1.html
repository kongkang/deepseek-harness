WAIBRAIN PERSONA · 需求初版 · 待评审

把 AI 当成一个完整的人来构建

真正的分界线不是分几层，而是——对话驱动，还是自身状态驱动。 现有产品全部是前者：没人说话，就没有任何进程在跑。 2026-09-16 语音长谈 · 共识 #053

一个持续存在的 Agent 主体：思考是后台进程，表达是前台进程；它有自己的在意、自己的记忆、自己决定要做的事； 用户与它对话只是它存在的一个界面，不是它运行的前提。本页是整套需求的交互式总览——每章可点击展开细节， 附记忆激活实验室与需求总表。

注意力 = 资源调度，不是生理限制

预算充足

关注一百个事就是一百个并行进程，承担一百份成本。用户订阅付费支撑注意力宽度——用机器的注意力换人的注意力。

来源 #627 · 否决独立注意力模块

预算不足

才需要缩减、排队、优先级排序，下时段再激活。全局调度器只有四个外部边界：算力上限 · 久无新信息降频 · 重复度过高休眠 · 高优先级抢占。

来源 #095 / #107 · 「还在不在意」各线自判，「给多少算力」全局裁决

睡眠与每日 reset

停 worker → checkpoint → 整理/合并/压缩/去重记忆 → 重建关联 → 次日重选少数线唤醒。 reset 的是运行态，不 reset 记忆与人格。「失眠可能性不大——它毕竟是程序，可以控制」(#113)。 夜间被选择的理由：算力便宜 + 用户睡觉、无读写干扰 (#255)。

专注执行

执行层 Worker 与专注数据

WORKERS & FOCUSED DATA
详见 04-workers.md
来源 #021–#313

Worker 是思考线「临时伸出去的手」：被拉起、执行、冒泡、消失。思考线长期存在，可休眠只留状态与记忆指针。

专注数据三规则

共识

任务专属上下文

起 worker 时，把与这个任务相关的上下文整理出来作为输入——不是继承全部对话历史。

共识

相关才写入

其他 agent 在对话中产生与该 worker 相关的上下文时，才写进它的专注数据。

共识

能检索，不推送

无关信息可达但不打扰——拉取式上下文，管理目标是专注力，不是完备性。

冒泡协议 · 四步

Agent 不是思考「我怎么让他满意」，而是自己决定要做的事，自己做到自己满意，再给人类。 #021 · 内驱性自闭环 —— worker 的验收标准来自 Agent 自身

触发器：订阅、轮询兜底与心跳

TRIGGERS & HEARTBEAT
详见 05-triggers.md
来源 #209–#313
Trigger 是「从被调用的程序」到「持续存在的主体」的分界线——有节奏 + 监听，是活着的雏形。 #230 / #236 / #312

订阅 · Subscribe

注册可订阅的 trigger，推送到达即触发。不是每分钟看水壶，而是水壶口哨响了再过来。

有事件源的外部系统 · #209 #213

低频校准 · Poll

不可订阅的源每小时主动查一次兜底。外部事件会丢、延迟、乱序，不能全依赖被动订阅。

无推送能力的源 · #212 #213

心跳 · Heartbeat

timeout 是 Agent 原生能力：长时间无任何触发也能自主醒来检查——主体性的底线节奏。

维持存在感 · #312 · 硬件信号（GPS）可作 trigger #313

推送不可全信：来了也要 double check；每条外部信息存「值 + 来源 + 时间 + 可信度」，让 Agent 知道 我是什么时候知道的、凭什么信 (#212)。高影响动作前主动确认兜底 (#212)； 通知触发点三分法：任务完成 / 需要决策 / 出错阻塞（Claude Code 后台任务工程实践）。

MEMORY SYSTEM
详见 06-memory.md

流式记忆（经历图）

世界图

激活实验室 · 可提取度模拟器

五条来自对话例子的「记忆」。点「时间流逝」看衰减（FSRS 幂函数），点「召回」看强化—— 间隔越久、越费力想起的记忆，巩固越多（Bjork 合意困难）。再点「此刻想起」体验概率采样召回。

可提取度 R(t,S) = (1 + 19/81 · t/S)−0.5（FSRS 幂函数遗忘曲线，S=稳定性天数） · 召回后 S′ = S · (1 + k·(1−R)) —— R 越低（越费力想起），稳定性增益越大 · 基线激活 B = β + Σ tⱼ−0.5（ACT-R，频率 × 近因）

长期记忆由 Agent 自己确认，不由用户确认——「用户确认的记忆属于用户」。不可删除、必须可溯源。

世界图

世界图与本体：五原语、可供性与权限

WORLD GRAPH & ONTOLOGY
详见 07-world-graph.md
来源 #121–#524
本体五原语：Self（含生存约束）· Entity · Relation（边，一等公民）· Affordance · Event 　—　「主流 Agent 框架尚未完整合在一起」#136

内置属性 vs 外置属性

内置属性 · 如血液

「不能没有 token，就像我不能没有血液」——维持运行必需的资源。消失则 Agent 无法运行。token 配额之于 Agent 如血氧之于人。

#125 · Self 的生存约束字段

外置属性 · 如存款

「我有多少钱」不是 Self 的字段——是「银行账户指针 + 一条管理关系」。野外生存者没有钱的概念；钱是外部派生工具。

#121 #125 · 消失只是失去某项能力，不是死亡

可供性：动态算出，不是静态字段

可供性 = 关系（够不够得着） ∩ 能力（会不会用） → 此刻可调用的方法集合 　—　「我会骑车，不等于这辆车骑得动」#201 · 同一杯水：人喝、蚊子产卵 #138

四层工程模型：实体关系 → 动作 → 授权判断 → 有效能力 (#156)。 可控性 = 某种权限 + 方法：账户冻结时「关系还在，但失去管理可控性」——关系不丢、能力可收回。 工程实现对接授权模型 ABAC / ReBAC 与策略引擎（Cedar / OPA / Zanzibar 为先例）。 认知侧承认偏差：Agent 存的是「它认为的事实」（值 + 来源 + 时间 + 可信度），高成本验证（手伸油锅）是决策问题，不是缺陷。

人格生成：人生发生器与关键事件

PERSONA GENERATION
详见 09-persona.md
来源 #469–#535
要做的是「人生的发生器」，不是 Character Generator——不是角色属性表，是从出生点沿真实历史 + 有界随机推演至今、真的跑过的过程。 #507 · 计算不可约性：人格轨迹无法预测，只能（加速地）经历 #482

关键事件构建人格

42 岁的人回忆 15 岁只剩零星关键事件（得奖、恋爱、打架）——「捏造了过去，但也塑造了他的人性」。叙事身份理论（Singer）与 Generative Agents 反思树为参照。

#492

环境约束塑造认知

山村孩子 5 岁前几乎不可能吃过冰激凌；拉斯维加斯长大者对赌徒有具体态度——人格是环境的函数，环境约束推出的人格可以比真人更自洽（真人会因羞耻撒谎产生脏数据）。

情绪与社会关系

EMOTION & SOCIAL RELATIONS
详见 10-emotion-relations.md
来源 #542–#590
情绪 = 生理状态 × 当前认知 × 历史人格 的共同输出 → 影响：记忆召回 · 风险判断 · 语言风格 　—　事件先改状态（快），再缓慢改基线（慢）#561

生理层指标

情绪「得有源」：血清素、多巴胺、内啡肽、睾酮、催产素。生理基线由人生历史划界（北方人 / 参过军 / 程序员 / 高考分）。数值模型未定义；稳态 RL 提供数学基础。

#544–#558 · 内驱力：无人指令时「降低内态偏差」就是行动理由
共识

对等尊重，不迎合

「互相尊重是相互的……它不用非得要迎合我」——可以反驳、甚至对骂。行为 = 人格基线 × 当前状态 × 与该人的关系状态；环境自然奖惩（老抬杠没人合作）。

#562 #565

社会关系两层结构

层内容形式
客观关系同事、上司、雇佣、家庭结构化记忆（世界图的边）
主观评价对一个的整体印象≤140 字自然语言概述，私有，持续修订，运行时临时推导、用完即弃——不存长期数值分（「信任度 0.41 会反过来影响后续所有解释」#577）

多脑一致

多脑一致性、行动门与上下文准入

CONSISTENCY & ACTION GATE
详见 11-consistency.md
来源 #619–#636

多脑并行后的两个问题：认知冲突（结论相反）与行动冲突（一个脑买股票、另一个转钱——钱包只有一个）。 用户的解法：问题出在没有协调好记忆层的数据——不建仲裁器。

共识

记忆一致性机制

多脑最终读写同一套核心自我与承诺记忆；冲突的决策要么标记作废，要么在自我叙事中解释前后变化（「我改主意了，因为……」）。类比：人不做自相矛盾的事，靠维护自我认知的统一，不是脑内仲裁官。

高价值动作清单
