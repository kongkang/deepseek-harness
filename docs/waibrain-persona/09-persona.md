# 人格生成：人生发生器与关键事件

## 生成器定位 ✅

- 要做的是"**人生的发生器**"，不是 Character Generator（角色属性表）——人格由真实跑过的经历生成，不是事后编排的传记（#507）。
- 人格必须"真的跑过"：从出生点沿真实历史 + 可控范围内的随机推演至今，启动时人生完整（#473–#498）。
- 极度加速、稀疏粒度地跑，但过程本身要发生（#507）。

## 种子：随机 + 贝叶斯初始值 ✅（#473–#479）

- 初始人格来自随机（"上帝模型的捏造"）：MBTI 或大五人格的随机数为种子。
- 种子 = 贝叶斯初始值，"重要但没那么重要"（#479）——初始值会在此后的人生推演中被大幅修正。
- 用户对 MBTI 的态度："没那么科学"，仅作种子。

## 推演：真实历史约束 + 有界随机 ✅（#486–#488）

以"32 岁、汉堡出生的女建筑师"为例：

1. 年龄定出生年（进而星座等派生属性）。
2. 沿**真实历史**回溯（那 32 年里世界真实发生了什么）。
3. 在**有效范围内随机**：考学、结婚、离婚等人生事件在文化/时代约束内抽样。
4. 启动时人生完整、记忆自洽。

环境约束塑造认知（#512）：山村孩子 5 岁前几乎不可能吃过冰激凌；拉斯维加斯长大者对赌徒有具体的态度；非洲儿童无法理解赌城——人格是环境的函数。

## 关键事件与叙事身份 ✅（#492）

- 人格由少数关键事件构建：42 岁的人回忆 15 岁只剩零星关键事件（得奖、恋爱、打架）——"捏造了过去，但也塑造了他的人性"。
- 对应研究：叙事身份（Singer 的 Self-Defining Memories）、Generative Agents 的反思树——见 [research-foundations.md](research-foundations.md)。
- 不同启动年龄只是初始值不同：从 25 岁或 35 岁启动的同款生成器，产出不同人格（#498）。

## 计算不可约性 ✅（#482、#507）

- 用户直觉提出"数据不可约性"：人生轨迹无法预测、只能经历；对话方对应为 Wolfram 的计算不可约性（computational irreducibility）。
- 工程含义：人格不能靠公式生成，只能靠推演运行产生；想看到 42 岁的人格就必须（加速地）跑到 42 岁。

## 拟真与干净数据论 🟡（#508–#515）

- 用户论点：环境约束推出的人格可以比真人更可信——真人会因羞耻而撒谎，产生脏数据污染后续推论；Agent 基于自洽经历"选择撒谎"是干净的数据。"就像正确的报错，虽然拿到报错，但这个报错是正确的。"
- 💬 保留分歧（#511）：对话方不认同"跑过一遍 = 真的经历过"——系统在因果上参与了过程，但过程仍是编造的。用户曾质问"你是故意迎合我吗"（#508）。分歧未消除，记录于 [open-questions.md](open-questions.md) OQ-5。

## 元认知由设定解决 ✅（#528、#535）

- 认知边界 = 职业设定 + 背景故事：医学院转行建筑 → 自然关注健康建材。
- 查证倾向由性格决定：INTJ 更信自己、查完更自信。
- 元认知 = 置信度与验证成本的权衡，不需独立模块。

## 人格是目标生成器 💬

调研补充（PEPA，IEEE RA-L 2026）：人格不是语气滤镜，而是**目标生成器**——人格描述合成终极目标，每日目标由前日运行记忆生成。这与"思考线的初始关注项由用户设置"（[03-thinking-threads.md](03-thinking-threads.md)）衔接：人格生成后，它应当自己产生在意。见 [research-foundations.md](research-foundations.md)。
