# 多脑一致性、行动门与上下文准入

## 问题 ✅

多个并行外脑/思考线同时运行后的两个一致性问题（#630–#636）：

1. **认知冲突**：两个脑对同一事实结论相反。
2. **行动冲突**：一个脑决定买股票、另一个决定转账——钱包只有一个。

对话方提出"最后的门"（行动仲裁层）：花钱、对外承诺、改变关系的高价值动作只能有一个生效决定（#630、#632）。

## 用户的解法：记忆一致性，不建仲裁器 ✅（#633、#636）

- 诊断："问题是出在没有协调好记忆层的数据"，不是缺仲裁者。
- 类比：人不做自相矛盾的事，靠的是维护自我认知/人设的统一，不是脑内仲裁官。
- 机制：多脑最终**读写同一套核心自我与承诺记忆**；冲突的决策要么标记作废，要么在自我叙事中解释前后变化（"我改主意了，因为……"）。
- 用户接受问题存在，但降维为数据协调实现。

## 高价值动作清单 🟡（未定义）

"哪些算高价值动作"（花钱的阈值？对外承诺的范围？）在对话中没有定义。行动门的最低要求即使不建独立仲裁器也需要：**同一资源（钱包/对外身份）的写操作必须有串行化点**——这是工程底线，与是否有"仲裁 Agent"无关。见 [open-questions.md](open-questions.md) OQ-4。

## 上下文准入 ✅（#626）

- "哪些东西有资格进入大模型上下文"必须在调用大模型**之前**决定。
- 与语音方案的代码级兴趣门（共识 5）同构：准入判断是代码/规则，不是模型调用——每加一层模型判断就多一次往返延迟。

## 否决模块回顾 ✅

对话后期的"上帝视角四缺口"审查（#468）逐项处置：

| 缺口 | 处置 | 理由 |
|---|---|---|
| 驱动力/价值系统 | 部分保留 → 生理层指标 + 稳态思想（[10-emotion-relations.md](10-emotion-relations.md)） | 无人要求时为何选 A 不选 B 需要内驱 |
| 自我模型（"我觉得我是什么"） | 保留 → 核心自我记忆 + 人格推演（[09-persona.md](09-persona.md)） | 非系统提示词，而是持续自我描述 |
| 元认知 | 已由设定解决（#528） | 置信度 × 验证成本，人设决定查证倾向 |
| 情绪（全局调制信号） | 保留 → 投影模型（#561） | 比当前状态更慢更深，长期影响认知与风险偏好 |
| 他者心智模型（追加） | ⭕ 否决（#615） | "我们不是为了表演一个人，而是构建他的自我"；感知外脑+上下文实时维护够用 |
| 世界模型/因果预测（追加） | ⭕ 否决（#619、#623） | 推理外挂脑可解决，"世界模型已经在记忆中了" |
| 独立注意力模块（追加） | ⭕ 否决（#627） | 转为资源调度（[03-thinking-threads.md](03-thinking-threads.md)） |

调研补充的弱点提示：模块化 ToM 在**说服/谈判密集场景**有可测提升（见 [research-foundations.md](research-foundations.md)）——若未来产品进入谈判域，可加轻量"对方建模"步骤（非独立模块）。

## 研究证据 💬

多 Agent 辩论（MAD）在 2025 年跨 9 基准的经验研究里常不优于单 Agent 基线，且有"多数暴政"从众问题——支持"不建辩论式仲裁器"的决定。冲突结论落库时带置信度与时间戳，由时序记忆做最终裁决（两个机制天然咬合）。见 [research-foundations.md](research-foundations.md)。
