# 人格化 Agent 需求（初版）

本目录是「把 AI 当成一个完整的人」这一产品方向的需求初版（v0.1）。来源是 2026-09-16 的一次 ChatGPT 语音长谈（649 条消息、约 5 小时），话题从三层架构推演到记忆、本体、人格生成、情绪与多脑一致性。本目录整理该对话中确认的需求、架构决策与开放问题，并补充针对性调研。

## 这份需求讲什么

一句话：**Agent 不该只是"你问我答"的程序，而是一个持续存在、有自己在意的事、自己决定做什么和说不说话的主体。**

核心结构是三层：表现层（说话的）、思考层（并行在想的一组"思考线"）、执行层（干活的 worker），加上贯穿三层的记忆系统与世界图。真正的分界线不是层数，而是**对话驱动还是自身状态驱动**——现有产品全部是前者，本需求要的是后者。

## 状态标注约定

- ✅ **共识**：对话中双方明确达成一致，可直接作为设计依据。
- 🟡 **用户提出，待细化**：用户单方表述的需求，机制未展开或未被挑战。
- 💬 **分析建议**：对话方提出、用户未明确表态的内容，供决策参考。
- ⭕ **否决**：明确否决的做法，后续争议以否决为准。

每条需求带编号（如 `MEM-03`）与来源消息号（如 `#021`），便于回溯原始对话。消息号对应 2026-09-16 语音长谈导出档案中的消息序号。
