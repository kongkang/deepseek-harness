# 开放问题与未收敛分歧

对话结束时"再无明显缺失的基础环节"（上帝视角四缺口全部处置完），但以下问题未收敛。按影响面排序；消息号指向 2026-09-16 对话档案。

## 架构与机制

### OQ-1 前提变化：强制送达 vs 允许浪费 🟡

- 张力：#038 要求"前提变化信息强制送达 worker"（防执行层过专注漏掉"演示取消了"）；#039–#041 允许知道取消也继续做（浪费有价值）。
- 本目录暂定口径（[03-thinking-threads.md](03-thinking-threads.md)）：强制送达保留、强制终止不做——待评审确认。

### OQ-8 自我状态与思考线的存储结构 🟡

- 用户自评（#159）："动态变化本质上还是没有抽象、没落实在存储结构。"思考线状态机、当前状态层（激活集合）如何持久化（字段、表、图节点？）未定。
- 关联：OQ-10 图选型。

### OQ-10 世界图存储选型 🟡→方向已定

- 图数据库 vs 关系型/NoSQL（#159、#162）：共识是"图是表达关系的视角，规则是算能力的函数"。第三部分定方向：「和这个模型最贴切的其实就是图」（#1170）、「图……应该是最终真实的结构，关系自由度最大、依赖有路径可循」（#1379）——网状图为基础表示；具体引擎（Neo4j/Graphiti 等）仍未选定。现成参照见 [research-foundations.md](research-foundations.md) B3。

## 第三部分之后新增的开放问题

### OQ-14 种子的最小基因与发育规则 🟡（2026-09-17 挂起）

- 收敛点：「reactive unit 作为种子细胞最少需要什么，才能长出事后叫'财务 Agent'的结构」（#1371/#1374）。种子=少量初始反应元+生长规则+连接方式+外部知识获取能力；发育规则（何时分化/复制/连接/稳定）未定义。约定下次直接从此点往下走（#1386）。

### OQ-15 内源性平衡机制 🟡（2026-09-17 新增）

- 「不害怕它疯长，我害怕它没有理由的复制而没有抑制逻辑」（#1379）；要的是内源平衡（类比博弈论均衡，「像自然界的平衡」#1381），非外部铲除。机制空白。

### OQ-16 三层叙事是否重写为平级反应单元网络 🟡（2026-09-17 新增）

- 第三部分将「主对话+外脑」再解释为平级节点网络（#1096/#1126/#1244）。用户定性为再解释而非推翻（#1193/#1377：功能需求未变）。是否/何时统一重构 [02-architecture.md](02-architecture.md) 的叙事，待 reactive unit 方向验证后定。详见 [12-updates.md](12-updates.md) 第三部分。

### OQ-17 工具三分离的实现 🟡（2026-09-17 未定案）

- 可见/可选/可执行三分离（#1051–#1067）：用户否决软提示（#1059）；暂定案为公共工具共享前缀、高权限工具 restrict 真删接受缓存分叉、远期自建推理层做解码级子集约束。缓存与权限分层、优先确定性——待确认。

### OQ-2 边实体化的粒度 🟡

- 悬置于 #172–#183：升级为节点的是"夫妻关系"这一**类型**，还是"A 和 B 是夫妻"这一**事实实例**？对话确认三层 schema（实例 → 关系类 → 边类型），但实体化触发条件未定案。

### OQ-3 主观评价的存储与更新机制 🟡

- 方向已定：≤140 字自然语言概述、私有、持续修订、运行时推导（#588–#590）。
- 未定：概述何时重写（每次交互后？夜间？）、由谁触发、多个概述版本是否留痕。

### OQ-4 高价值动作清单与串行化点 🟡

- "最后的门"被降维为记忆一致性（#633），但"哪些算高价值动作"未定义；同一资源（钱包/对外身份）的写操作串行化是工程底线，落点未设计。

### OQ-9 记忆更新遍历难题 🟡

- "跟搬家产生交集的所有记忆很难全部遍历出来"（#347）。方向：夜间并行 worker / 小快模型全量清洗（#353）。触发条件（何时启动全量清洗）、成本上限未定。

## 哲学与术语

### OQ-5 "跑过 = 经历过"分歧 ⭕ 未收敛

- 用户：环境约束推演的人格可比真人可信，"正确的报错"论（#512）；对话方：跑过一遍不等于真的经历过，过程仍是编造的（#511）。底层分歧未消除；不影响机制设计，影响产品叙事。

### OQ-6 偏见 vs 先验的术语 🟡

- 用户坚持"偏见 = 中性区别对待"，对话方改称"先验模型"——实质收敛，命名未统一（#578–#590）。文档暂用"贝叶斯印象/先验"。
