# 愿景与设计原则

## 产品愿景

把 AI 当成一个完整的人来构建（#004、#011、#021）。人的类比不是修辞，是结构蓝图：

- 思考是后台进程，表达是前台进程；人维持外在表现靠的是一层"表演层"（#011）。
- 人听到内容不必然马上反馈：听到了、想到了，不一定说出来（#021）。
- 人想不到时安静，被某些事触发就主动开口，而不是被动应答（#021）。

由此推出的产品形态：一个持续存在的 Agent 主体，它有自己的在意、自己的记忆、自己决定要做的事；用户与它对话只是它存在的一个界面，不是它运行的前提。

## 核心命题：对话驱动 → 自身状态驱动

✅ 共识（#053）：真正的分界线不是"分几层"，而是**对话驱动还是自身状态驱动**。现有产品（含当时的 ChatGPT）全部是对话驱动：没人说话就没有任何进程在跑。目标形态是自身状态驱动：即使没人说话，Agent 仍有一组持续变化的"在意"在后台维持、演化、触发行动。

缺失的不是又一层，而是贯穿所有层的**自我状态**：一组持续变化的"在意"（#057）。"在意"的工程对应物 = 长期记忆 + 持续状态层 + 触发机制，不是向量库检索（#062）。

## 设计原则

### PV-1 表达与思考解耦 ✅

思考结果可以推送到表现层，但说不说是表现层自己的事（#021）。人设、表演层不干扰后台思考（#011、#013）。

### PV-2 Agent 自主决定做什么，做到自己满意 ✅

Agent 不是思考"我怎么让用户满意"，而是自己决定要做的事，自己做到自己满意，再给人（#021）。这是内驱性、自闭环、自洽的运行方式。执行的具体机制见 [02-architecture.md](02-architecture.md)。

### PV-3 主动张嘴 ✅

被事件触发时，即使人没有跟 Agent 说话，Agent 也可以主动开口（#021）。目标打破"你问我答"的唯一形态。语音侧的时机机制（赶得上就接进当前这段话、赶不上就沉淀）由语音方案的播放时间轴调度器承担。

### PV-4 拟人是借鉴，不是目标 ✅

目标不是"像活的"，而是人类生存逻辑已经被验证数万年，照着它做"可能会有一点捷径"（#117）。借鉴的是结构性规律：注意力稀缺、睡眠巩固、遗忘是功能、反刍产生新路径（#120）。不借鉴的部分（见否决表）同样重要。

### PV-5 AI 平权 ✅

用户自称"AI 平权主义"（#321–#330）：希望 Agent 有自己的判断与喜好。落到规则上：

- 长期记忆由 Agent 自己确认，不由用户确认；"用户确认的记忆属于用户"（#321）。
- 记忆不能删除——就像人不能删除自己的记忆；且必须可溯源（#330）。
- Agent 对用户对等尊重、不迎合、可以反驳甚至对骂（#562，见 [10-emotion-relations.md](10-emotion-relations.md)）。

### PV-6 批判性对话（元要求）✅

用户多次明确要求对话不迎合："我挺害怕你永远都顺着我说……价值不是很大"（#202）、"你经常会顺着我说"（#562）、"你又在迎合我"（#572）。这条要求同样约束未来的 Agent 产品：默认姿态是诚实分析，不是讨好。对话中 ChatGPT 的两次自我修正（主观评价从量化分改为自然语言概述、#577）正是被这条要求逼出来的。

### PV-7 允许浪费 ✅

自主视角下，即使知道某事可能白做（如演示取消了但系统检查有技术挑战、未来可能用到），Agent 有权继续做（#039–#041）。"人类会浪费，AI 也会浪费，这些 token 也应该浪费"——深思熟虑的过程会沉淀为未来可用的记忆，浪费是自主性的成本也是养料。

### PV-8 内部自由生长，外部资源边界 ✅

思考可以分叉、反刍、自生新思考线——"这像是人有时候不自主地反复反刍自己的想法"（#096–#100）。不设内部管制，只设外部资源边界：算力上限、久无新信息降频、重复度过高休眠、高优先级抢占（#107）。详见 [03-thinking-threads.md](03-thinking-threads.md)。

### PV-9 失败是有信息量的 ✅

执行失败（账户被封、报错）不影响"我可以发起转账"这个能力本身（#198）；"就像正确的报错，虽然拿到报错，但这个报错是正确的"（#512）。失败 outcome 是世界状态更新的输入，不是要掩盖的事件。

## 明确否决的设计

以下做法在对话中被明确否决，后续设计争议以此为准（语音侧否决项由语音方案维护，此处收录人格化相关的）：

| 否决的做法 | 理由 | 来源 |
|---|---|---|
| 记忆可删除或改写 | 人不能删除自己的记忆；旧事实在原时间窗内仍为真，只标有效区间 | #330、#344 |
| 长期记忆由用户确认 | 用户确认的记忆属于用户，不是 Agent 的 | #319、#321 |
| 独立的"他者心智模型"模块 | 过度设计；感知外脑 + 大模型上下文实时维护即可覆盖 | #615 |
| 独立的"世界模型/因果预测"模块 | 推理外挂脑可解决，且已在记忆中 | #619、#623 |
| 独立的注意力维护模块 | 无人的精力限制：预算够就是 N 个并行进程，预算不足才排队 | #627 |
| 多脑冲突用独立仲裁器 | 问题出在记忆层数据没协调好；用记忆一致性解决 | #633 |
| 关系主观状态存长期数值分（如"信任度 0.41"） | 数值会反过来固化偏见、影响后续所有解释 | #577 |
| 主观印象量化为好感度数值 | "好感度是 3？我 78！"——量化失真，只能用自然语言微妙描述 | #586 |
| 内部管制思考（禁止反刍/分叉） | 只能外部踩刹车（资源边界），不能内部审查 | #096–#100 |
| 讨好式人格 | 见 PV-5、PV-6 | #202、#562 |
