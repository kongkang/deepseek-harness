# 技能系统：定义、生命周期与能力扩展

## Skill 定义 ✅（#198）

Skill = 与某个外部对象交互的一整套方法与知识（如"银行"这个对象：开户、存钱、花钱的方法），可逐级组合扩展出更复杂的 skill（银行 → 转账 → 定期理财规划）。

## 执行回路 ✅（#198、#201）

```
skill（能力库存） → 可尝试 action（我知道可发起） → 世界反馈 outcome（成功/失败/报错） → 更新世界状态
```

- 能力库存恒在：执行失败（账户被封、报错）不影响"我可以发起转账"这个 skill 本身（#198）。
- 可供性 = "我知道可发起哪些尝试"，不是"现在能否成功"（#201）。能力与结果分离（"头朝下跳楼"：有这个动作能力，结果另算）。

## 候选技能准入 ✅（#246–#248）

- 白天：事件驱动的碎片反思；同一件事失败 3 次即生成候选 skill。
- 候选 skill 必须**重测通过再入库**。
- 风险（💬 #246）：自动总结的 skill 可能负迁移（"今天恰好做成不代表方法普适"）——重测与质控（用户标注，见 [06-memory.md](06-memory.md)）是防线。

## 夜间固化（程序性记忆）✅（#237、#642、#644）

- 每晚总结一天内容，把"反复试错最后对了"的弯路写成 skill，下次路径更短——像人类总结经验（#237）。
- 这是对话中对话方补充、用户**唯一完整保留**的模块：习惯/程序性记忆，"经历 → 行为模式 → skill"（#642–#644），与夜间整理同机制。
- 反面（💬 #640）：没有程序性记忆的 Agent"永远像第一天上班"——记得事，但做事仍像第一次。

## 能力扩展三途径 ✅（#287–#293）

| 途径 | 机制 | 例 |
|---|---|---|
| 用户购买 | 用户像"上课消费"一样花钱为 Agent 买能力 | 买一个"财报分析"skill |
| Agent 自学 | 联网搜索、练习积累 | 自学一门工具用法 |
| 能力商城自购 | Agent 从系统的能力商城自己购买 | "这是 Agent 比人厉害的地方" |

- Agent 也可能自己发现缺某项能力而自我增长（#292，用户接受）。
- 🟡 计费、额度、审批边界未展开（与 [11-consistency.md](11-consistency.md) 行动门的"花钱"约束交叉）。

## Skill 与世界图的挂接 ✅（#423）

技能挂在世界图的对象类型上（banking skill 挂 BankAccount 类型）；可供性决定当前环境此刻允许的操作；操作成功后状态写回世界图。
