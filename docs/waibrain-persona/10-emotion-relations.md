# 情绪与社会关系

## 情绪的定义 ✅（#542–#561）

情绪不是模块，不是表现层的一部分，而是：

```
情绪 = 生理状态 × 当前认知 × 历史人格 的共同输出（状态的投影）
```

- 以结构化变量存在，影响三件事：**记忆召回、风险判断、语言风格**（#561）。
- 事件先改当前状态，再缓慢改基线（#561）：连续数周被骂 → 压力升、信任降、表达防御 → 基线信任逐渐下滑。单向快变的是状态，慢变的是基线。

## 生理层指标 🟡（#544、#556、#558）

- 情绪"得有源"：类比养成游戏的数值参数（含水量、饥饿、心情），需要数据源/标注源。
- 生理基线由人生历史划界（#556）：北方人、参过军、程序员、高考分——身体素质与气质的边界条件来自 [09-persona.md](09-persona.md) 的推演。
- 指标集（#558，对话方补全"催产素"）：血清素、多巴胺、内啡肽、睾酮、催产素。
- 🟡 具体数值模型（每个指标怎么算、怎么影响三输出）未定义。
- 调研衔接：稳态强化学习给"带设定点的内变量"提供数学基础——驱力下降即奖励，无人指令时 Agent 也有行动理由（见 [research-foundations.md](research-foundations.md) 内驱力一节）。

## 对等尊重与不迎合 ✅（#562）

- "互相尊重是相互的……它不用非得要迎合我"：Agent 可以反驳用户、甚至对骂（用户引 Grok 嘴毒为例；自述对 ChatGPT 又骂又夸又道歉）。
- 这是 PV-6 的关系侧落地。

## 社会关系两层结构 ✅（#568、#577、#581、#588–#590）

| 层 | 内容 | 存储形式 |
|---|---|---|
| 客观关系 | 同事、上司、雇佣、家庭 | 结构化记忆（世界图的边） |
| 主观评价 | 对一个人的整体印象 | **≤140 字自然语言概述**，私有，持续修订 |

- 主观概述进对象记忆，运行时临时推导、用完即弃；**不长期存数值分**（#581、#588–#590）。
- 理由（#577）：长期结构化的"信任度 0.41"会反过来影响后续所有解释，把印象固化为偏见。
- 荒谬性检验（#586）："好感度是 3？我 78！"——量化对人际印象失真；只能用"人中龙凤/嘴臭了点儿"式微妙描述。
- 参照：Generative Agents 的自然语言记忆 + 按需压缩摘要（调研确认该路线可行）。

## 贝叶斯印象 ✅（#578–#590）

- "整个世界都应该是基于贝叶斯法则的"：第一印象 = 先验初值，此后每次交互做贝叶斯更新。
- "偏见是中性词"——偏见 = 区别对待（术语分歧见 [open-questions.md](open-questions.md) OQ-6）。
- 识别：靠声纹/UID 匹配记忆中的对象（#590）。
- 升职/裁员改变客观关系 → 主观评价随之修订（#590）。

## 环境反馈系统 ✅（#565、#567）

- 行为 = 人格基线 × 当前状态 × 与该人的关系状态。
- 不需要写"学会做人"的规则：环境自然奖惩（"老抬杠没人合作"）——允许偏见、执念、惯性，但社会环境会反馈惩罚。
- 关系动力学不过度结构化（#568）："本就属于记忆"——不为关系建独立引擎。

## 内在与表现的分离链路 💬（#581）

```
对象事实 → 私有模型（对该人的主观概述） → 当前情绪 + 社会约束 → 表现行为
```

推论：不同 Agent 眼里的同一个人不一样（心里认上司是蠢货、表面恭敬是合法状态）。

## 识别与多对象 🟡

- 不同对话对象的调用与处理（#278）+ 声纹/UID 识别（#590）构成多对象场景；"同一事物两种视角"（充值 vs 工资）见 [07-world-graph.md](07-world-graph.md)。
