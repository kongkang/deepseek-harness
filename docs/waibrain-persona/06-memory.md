# 记忆系统：双层存储、激活召回与时间轴

记忆系统是人格的载体：记忆由 Agent 自己确认（PV-5）、不可删除、可溯源、随时间衰减、被召回强化。本章是全部需求里机制推演最深的部分。

## 双层存储 ✅

记忆分两层（#424–#432）：

| 层 | 名称 | 形态 | 回答的问题 |
|---|---|---|---|
| 第一层 | 流式记忆（经历图） | 日志式，逐条追加 | "发生了什么"（原始证据） |
| 第二层 | 世界图 | 结构化实体-关系-状态图 | "世界现在什么样"（可操作认知） |

- 逻辑上是一张大图，存储可以分开，靠统一 ID + 溯源字段关联（#437、#441）。
- 世界图有 schema（#429），本体设计见 [07-world-graph.md](07-world-graph.md)。
- 技能挂对象类型；可供性决定当前环境允许的操作；操作成功后状态写回世界图（#423）。

## 记忆强度与遗忘 ✅

- 记忆随时间衰减，被想起即补齐（#368–#379）；强度基准值 0、可正可负动态变化。
- "你越不想它，就越容易忘它"（#379）。
- 记忆强度/遗忘度是显式字段，不是隐式行为（用户反复追问"用什么样的算法实现"，#391、#406、#416）。

### 激活度模型（研究映射）

对话推演的机制与三个成熟研究几乎一一对应（调研详见 [research-foundations.md](research-foundations.md)）：

| 本需求概念 | 对应研究 | 机制 |
|---|---|---|
| 强度=频率×近因 | ACT-R 基线激活（Anderson） | B_i = β_i + Σ_j t_j^(-d)，d≈0.5；使用次数与近因共同决定激活 |
| 平时想不起、提示可恢复 | Bjork 新失用理论 | 存储强度（只增不减）与提取强度（随闲置衰减）分离；"记得深≠想得起" |
| 可训练的遗忘参数 | FSRS | Difficulty/Stability/Retrievability 三变量；幂函数遗忘曲线 R(t,S)；参数可从 Agent 自身召回日志训练 |
| 联想扩散 | Spreading activation | 相关概念互相激活，有限深度 |

## 召回即强化与 Trace ✅

- 召回生成**调用痕迹（Trace）**而非修改原记忆；Trace 是元数据，用于计算当前可提取强度（#405、#411）。
- 每次回忆追加时间戳，历史不覆盖；频率与近因都重要（#415）。
- Trace 本身不是被检索对象（#419）。

### 两段式检索 ✅（#419）

1. 向量检索原始记忆（粗召回）。
2. 读 Trace 计算激活度，重排序。

### 概率采样召回 ✅（#451、#462）

最终召回 = Softmax + 噪声的**概率采样**，不是取最高分。同一句话在不同状态下激活出不同记忆，"不是 Bug，是它那一刻是谁的一部分"（#451）。

### 向量检索的局限 ✅（#372–#389）

向量检索度量的是相关性不是因果性（"粉色的大象"反例：越叫你不想，越被激活）。命中即加强记忆（召回即强化的由来）。

## 时间轴记忆 ✅

- 旧事实在原时间窗/语境下仍为真，**不应覆盖，只标记有效区间**（#332、#341、#343）。
- 例：广州楼下有好吃的肠粉；搬家北京后该事实过期，但"去年你说楼下有好吃的肠粉"仍为 true（#343）。
- 夜间整理时把当日数据与全历史比对，相关旧数据"标记有效时间截止到今天"；只标过期、不改写不删除（#355、#359、#366）："更新之前的数据，但是我不改写之前的数据"。
- 调研补充：工程上对应双时态建模（valid time + transaction time），Graphiti 已验证"新事实使旧边失效而非删除"的路线（见 [research-foundations.md](research-foundations.md)）。

## 当前状态层（工作记忆）✅

新增层（#451、#457）：思考脑之前、每轮不清零、缓慢漂移的带权重激活集合——"最近脑子里还热着什么"（对象/概念/目标/未完成事项）。

算法循环（#462）：

```
触发 → 更新当前状态 → 激活扩散（有限深度）→ 综合打分 → Softmax 采样 → 再更新 → 思考
        ▲                                                            │
        └────────────────────────────────────────────────────────────┘
```

综合打分 = 语义相似度 + 当前激活 + 记忆激活 + 目标匹配（#462）。

实现路径（#463、#464）：当前状态层可先**脱离大模型用刚性代码跑**（"刚性的代码，它就那样跑就可以了"）最小可行集，之后逐步用 LLM 做实体关系提取与解释。

## 夜间整理（睡眠的记忆部分）✅

- 每晚总结一天内容：整理、合并、压缩、去重、重建关联、标记过期（与 [03-thinking-threads.md](03-thinking-threads.md) 睡眠一节同一机制的记忆侧）。
- 夜间算力充裕（8 小时可用大量 token）、用户睡觉无读写干扰（#255、#359）。
- "复杂和难是两件事"（#361）：全历史比对复杂但可行。
- 极端情况：起多个并行 worker，或用小快模型全量过一遍数据做"增量记忆"清洗（#347–#353）。
- 对应研究：Letta sleep-time compute——空闲期由独立 agent 重写记忆块，同精度可省 5× 测试期算力（见 [research-foundations.md](research-foundations.md)）。

## 用户标注（记忆质控）✅

- 每晚睡前 3–5 个问题，向用户确认当天的录音/数据（#257）。
- "用户的标注会让它的数据变得更准"，适合长期记忆存留（#257）。
- 原则：**先校准事实，再总结经验**（#263）——防止错误认知沉淀成错误 skill。
- 挑问题的策略可借鉴 Active Learning：挑不确定的问题问（调研补充）。

## 记忆自主性 ✅

- 长期记忆由 Agent 自己确认，不由用户确认；"用户确认的记忆属于用户"（#319、#321）。
- 记忆不能删除（人不能删除自己的记忆），必须可溯源（#330）。
- 对话中最实质的一次分歧修正：ChatGPT 先引入"长期记忆=用户确认的事实/偏好"的通说，被用户否定后改为"Agent 自我确认"（#318–#321）。

## 记忆更新遍历难题 🟡

"跟搬家产生交集的所有记忆，很难全部遍历出来"（#347）。用户给出的方向：夜间并行 worker / 小快模型全量清洗。机制未完全收敛，见 [open-questions.md](open-questions.md) OQ-9。

## 拒绝的做法

- 覆盖或删除旧记忆（见 PV-5 与时间轴一节）。
- 把 Trace 当作被检索对象（#419）。
- 纯 top-1 确定性召回（#451：概率采样是人格的一部分）。
