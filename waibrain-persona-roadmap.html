需求一句话

THE ONE LINE

对话驱动（现状）

没人说话，就没有任何进程在跑。

Agent 是被调用的程序 所有产品都停在这里
➜

自身状态驱动（目标）

没人说话，「在意」仍在后台维持、演化、触发行动。

持续存在的主体 自己决定做不做、说不说 记忆是人格的载体

三层架构

EVENT-DRIVEN LOOPS

一切输入先进事件流，各层通过事件解耦；结果沿冒泡协议回流。

事 件 流 · 唯 一 入 口
用户话语 订阅推送 定时心跳 worker 冒泡
▼
L1 · SPEAK

表现层

说这段话的它。维持人设，决定说不说、怎么说，不做深度思考。

L2 · THINK

思考线网络

并行的「在意」。每条一个长期关心，可休眠唤醒，维护「为什么做」。

L3 · ACT

Worker 群

临时伸出去的手。专注数据内执行，做完冒泡、消失。

▼ ▲ 读写
共享底座 流式记忆 世界图 当前状态层「脑子里还热着什么」
冒泡回路：worker → 思考线总结 → 推送 ≠ 说 → 表现层自主决定

九个工作流

WORKSTREAMS 点击卡片展开细节 · 点击依赖跳转
WS-1

事件流 + 触发器

全新
一切输入先进事件流；订阅 / 轮询 / 心跳三类触发。
现状：无统一入口，纯消息驱动
依赖无
  • 用户话语 · 订阅推送 · 心跳 · 冒泡，统一为事件
  • 推送不可全信：外部信息存「值 + 来源 + 时间 + 可信度」
  • 一切主动性的地基（ARCH-6）
WS-2

常驻思考线

有雏形
外脑从每轮一次性分支 → 常驻、有状态的「在意」。
现状：外脑 = 一次性 fork 雏形，底座已支持常驻、编排未用
依赖WS-1
  • 状态机：活跃 / 休眠 / 合并 / 结束 + 开线三门槛
  • 专注数据：任务专属上下文，可检索但不推送
  • 冒泡三分法：完成 / 需决策 / 出错
  • 注意力 = 资源调度，四条外部边界，不做内部审查
WS-3

记忆系统

全新
流式记忆 + 激活召回 + 双时态 + 夜间整理。
现状：无；机制推演最深的一章
依赖较独立
  • 激活度 = 频率 × 近因（ACT-R）+ Trace 调用痕迹
  • 两段式检索 + Softmax 概率采样——同一句话不同状态召回不同记忆，是特性
  • 旧事实只标有效区间，不改写不删除
  • 当前状态层先用刚性代码跑最小集，不上大模型
  • 记忆由 Agent 自己确认，不可删、可溯源
WS-4

世界图 + 本体

全新
五原语元模型；存最小事实，能力由规则实时算出。
现状：无；存储选型待拍板（D2）
依赖WS-3
  • Self / Entity / Relation / Affordance / Event，边是一等公民
  • 可供性 = 关系 ∩ 能力，动态算出
  • 认知标注：「我认为的事实 ≠ 世界的事实」
  • Schema 后验：先存事实，类型从实例生长
WS-5

技能系统

全新
失败 3 次生成候选 skill，重测通过才入库；夜间固化。
现状：无
依赖WS-3WS-4
  • 能力库存恒在：执行失败不影响「我会」
  • 技能挂世界图对象类型，成功后状态写回
  • 扩展三途径：用户购买 / 自学 / 商城自购
WS-6

人格生成

全新
人生发生器：真实跑过推演，不是角色属性表。
现状：无；最大单点投入
依赖WS-3WS-4
  • 随机种子（大五）→ 真实历史约束 + 有界随机推演
  • 关键事件构建人格；启动时人生完整、记忆自洽
  • 计算不可约：想看 42 岁的人格，就必须（加速）跑到 42 岁
WS-7

情绪 + 关系

全新
情绪是状态的投影，不是模块。
现状：无；数值模型未定义、🟡 项最多
依赖WS-3WS-6
  • 情绪影响三件事：召回 / 风险判断 / 语言风格
  • 主观印象 = ≤140 字自然语言概述，否决数值分
  • 贝叶斯印象：第一印象是先验，交互做更新
WS-8

一致性 + 行动门

全新
不建仲裁器，靠记忆一致性兜底。
现状：无；串行化点是工程底线，要早做
依赖WS-2WS-3
  • 同一资源（钱包 / 对外身份）写操作必须串行化
  • 冲突结论带置信度 + 时间戳落库，时序记忆裁决
  • 多 Agent 辩论常不优于单 Agent——支持不建仲裁器
WS-9

主动说话闭环

有雏形
被触发时，没人说话也能开口。
现状：闪念回插 = 被动雏形，要等下轮
依赖WS-2语音A/B1
  • 触发 ≠ 说：表现层自主决定说不说
  • 语音侧时机 = 播放时间轴调度（赶得上就接，赶不上就沉淀）
  • 打字模式先验证：Web 里主动发消息
